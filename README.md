# ASCII Tetris // Terminal 👾

A responsive, terminal-style Tetris game built entirely from scratch using **Vanilla HTML, CSS, and JavaScript**. No libraries, no frameworks, just pure code.

## 🚀 Features

- **Retro Terminal Aesthetics:** A beautifully crafted monochrome aesthetic that makes you feel like a hacker from the 90s.
- **Dynamic Color Themes:** Click the `THEME` button to cycle through 4 built-in retro colors: 
  - 🟢 Classic Green (Default)
  - 🟠 Amber (CRT Monitor Style)
  - 🔵 Cyan
  - 🟣 Purple
- **Interactive Grid Hover:** The background grid dynamically reacts to your mouse movements, illuminating individual squares as you hover over them.
- **Responsive & Mobile Ready:** Perfect scaling for large PC monitors and features an optimized layout with on-screen touch controls for mobile devices.
- **Solid ASCII Blocks:** Game pieces are beautifully rendered using solid block characters (`██`) for that perfect retro terminal fidelity.
- **Score Tracking:** Local storage saves your High Score across sessions.

## 🎮 How to Play

### Desktop Controls:
- **Left/Right Arrow** (`A` / `D`): Move piece left or right
- **Up Arrow** (`W` / `X`): Rotate piece
- **Down Arrow** (`S`): Soft Drop
- **Spacebar**: Hard Drop (Instant)
- **P** or **ESC**: Pause / Resume Game
- **Enter**: Quick Restart

### Mobile/Touch Controls:
- A dedicated touch control panel will automatically appear on smaller screens.
- Alternatively, swipe gestures are fully supported:
  - **Swipe Left/Right:** Move piece
  - **Swipe Down:** Soft drop
  - **Swipe Up:** Rotate
  - **Hard Swipe Down:** Hard drop

## 🛠️ Technologies Used

- **HTML5** - Semantic structure and layout.
- **Vanilla CSS3** - Custom variables, responsive media queries, gradients, and dynamic background grids.
- **Vanilla JavaScript** - Game engine, matrix rotations, collision detection, and DOM manipulation.

## 💻 Run Locally

Running the game is as simple as it gets. No build steps or `npm install` needed!

1. Clone the repository:
   ```bash
   git clone https://github.com/PGGAMER9911/PixeTetris-ANCII.git
   ```
2. Navigate into the directory:
   ```bash
   cd PixeTetris-ANCII
   ```
3. Open `index.html` in your favorite web browser.
